# Intent-V2

Greenfield INTENT HOME launcher (`com.intent.launcher`) v0.0.01.

## Build

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

## Scope

First evolving-intention flow (Spanish scenario) on a brand-new HOME launcher — not the full INTENT vision, and not a reuse of intent-app / com.intent.coach.
